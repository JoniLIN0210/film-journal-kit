观影志 · Film JournalHow it works ↓

你的观影志One click. Every film you've ever seen.

把你在豆瓣标记过的每一部“看过”，变成一本属于你的观影档案：片库、日历、短评、口味分析，一份年度报告，一座收集了各国版本海报的海报馆，还有可以直接发朋友圈的长图。全部在你自己的电脑上生成，不需要把账号交给任何人。

01 — How it works

三步，大约五分钟

1

把按钮拖到收藏栏

用鼠标按住下面这个黄色按钮，拖到浏览器顶部的收藏栏（书签栏）里，松手。只需要做一次。

🎬 生成我的观影志 拖我

看不到收藏栏？按 ⌘+Shift+B（Mac）或 Ctrl+Shift+B（Windows）把它显示出来。

拖不动？，然后新建一个书签，把网址一栏换成这段代码。
2

打开你的豆瓣“看过”

在同一个浏览器里登录豆瓣，打开“我看过的影视”页面。

打开我的“看过” ↗

登录只在豆瓣官网进行，这个工具看不到你的密码。

3

点一下收藏栏里的按钮

页面上会出现一个蓝色的框，选“观影志 + 海报馆”或“只要观影志”。等进度走完，会自动下载一个压缩包。先解压（Windows 右键压缩包选「全部解压缩」，Mac 双击压缩包），再打开解压出来的文件夹里的 index.html。

300 部左右：只要观影志约 7 分钟，加上海报馆约 30 分钟（要逐部读取海报页，放慢速度以免被豆瓣要求验证）。进行中请不要关闭页面。想多收集一些海报版本？先看下面的「海报馆是怎么来的」。

03 — The Poster Room

海报馆是怎么来的

选“观影志 + 海报馆”就会生成。下面左边是不用做任何设置就有的；右边是一个可选步骤，需要你自己判断要不要做。

默认就有无需设置

  • 你看过的每一部都有海报。按你豆瓣“看过”列表逐部读取它在豆瓣的“海报”页，按豆瓣用户的喜欢排序，取最受欢迎的正式海报和预告海报（每部最多 6 张），标出国家 / 地区版本。
  • 你打了 4 星以上的，再收集最多 3 张同人与艺术再创作。
  • 看起来一样的版本会自动合并，不会一张图出现好几次。
  • 经典海报赏析。我们整理并核实过 46 部经典影片的海报故事（设计师、设计思路、出处），例如《寄生虫》《楚门的世界》《千与千寻》。你看过其中哪几部，那几部的名作海报就会排在最前面，标上“名作”，并附上赏析；点“名作导览”可以只看这些。
赏析是固定收录的内容，每个人能看到多少条，只取决于你看过这 46 部里的几部，和下面的 TMDB 密钥无关。赏析配的那张名作海报会从 TMDB 的公开图片服务器下载（不需要密钥）；如果你的网络连不上，有的会换成豆瓣上的同一张海报，其余的赏析文字照常显示，只是不对应具体某一张海报。

可选：用 TMDB 收集更多版本自己决定

TMDB（The Movie Database，themoviedb.org）是一个国外的电影资料库，海报版本比豆瓣多。填入一个 TMDB 的 API 密钥后，每部影片会多收集最多 6 张：各个语言的版本（英文版、日文版、法文版……）和没有文字的“无字版”。

不填完全没关系，海报馆照样完整生成，只用豆瓣的海报。

请先读这几点，再决定要不要做：
  • 密钥要你自己在 TMDB 官网注册账号、自己申请。这是 TMDB 官方的要求，我们不提供、也不代办密钥。
  • 是否申请、怎么使用，由你和 TMDB 之间约定，适用 TMDB 的使用条款（免费密钥限个人、非商业用途）。这一步与本工具的提供者无关，相关问题请以 TMDB 官网为准。
  • 密钥只在你自己的浏览器里、只在这一次生成中使用，不会保存，也不会发给我们或任何其他人。
  • TMDB 在国内访问可能不稳定。连不上时会自动跳过，只用豆瓣海报，不影响其他部分。

如果你决定要，大致这样申请（约 5 分钟，页面以 TMDB 官网为准）

  1. 打开 themoviedb.org 注册页，注册一个账号，去邮箱点验证链接。
  2. 登录后点右上角头像 →「设置 / Settings」→ 左侧「API」→ 申请一个新的 API 密钥（选 Developer / 开发者），同意使用条款。
  3. 按页面要求填写用途说明：用途类型可选个人（Personal），应用名称、简介如实写“个人观影记录 / 海报收藏”即可；网址一栏没有网站的话按页面提示填写。
  4. 提交后，页面上会显示 API 密钥（API Key），复制它。
  5. 回到上面第 3 步：点收藏栏按钮后，在蓝色框里展开「高级：加入 TMDB 海报」，把密钥粘贴进去，再点“观影志 + 海报馆”。
04 — FAQ

常见问题

安全吗？我的账号会不会被拿走？

不会。按钮只在你自己的浏览器里读取你自己的“看过”列表和影片页面，生成好的文件直接下载到你的电脑，不经过任何服务器，也碰不到你的密码。

可以用手机吗？

生成需要电脑。生成好的观影志在手机上也能看：把文件夹发到手机，或者上传到网站托管后用链接打开。分享长图生成后可以直接存到手机相册。

以后看了新电影怎么更新？

再点一次收藏栏里的按钮，下载新的一份，替换掉旧的文件夹就好。

想要一个能发给朋友的链接？

把解压后的整个文件夹上传到任意静态网站托管（GitHub Pages、Netlify、Vercel 都免费），就会得到一个公开链接。不想折腾的话，直接发长图最省事。

进度停住了或者提示“没能完成”？

豆瓣偶尔会限制过快的访问。等几分钟，刷新豆瓣页面，再点一次按钮即可。详情没读全也会照常生成，只是部分影片的导演、时长用简要信息代替。

海报馆怎么看？

海报馆是全屏放映的：← → 看同一部的不同版本，↑ ↓ 换一部，空格自动播放，I 打开索引按年份、五星、有赏析筛选。海报从哪来、TMDB 密钥要不要填，见上面的「海报馆是怎么来的」。

年度报告看的是哪一年？

默认是你最近有标记的一年。想看其他年份，在 report.html 的地址末尾加上 ?y=2025 这样的年份。
